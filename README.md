# NOVA GAMES

A React-based futuristic gaming download portal with separate pages for home, games, categories, and about.

## Features

- Multi-page React site with client-side routing
- Separate navigation pages: Home, Games, Categories, About
- Real-time game search and platform filtering
- Detailed game pages with requirements, guide, screenshots, and trailer
- Admin-editable data in `src/data/games.js`
- Responsive design with premium dark glassmorphism styling

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal.

## Customize games

Update game entries in `src/data/games.js` to change titles, descriptions, screenshots, download URLs, requirements, and notices.
